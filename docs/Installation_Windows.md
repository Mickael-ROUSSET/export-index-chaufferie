# Installation Windows

1. Installer Python 3.10+ et son lanceur `py`.
2. Télécharger et extraire le dépôt GitHub dans un dossier accessible en écriture.
3. Exécuter `Installer.cmd` (Internet requis pour installer openpyxl).
4. Renseigner `[export] repertoire` dans `config.ini`.
5. Exécuter `Exporter.cmd` et consulter le classeur produit.

Dépannage : vérifier `py --version`, les chemins, les droits et que le fichier Excel n'est pas ouvert.
