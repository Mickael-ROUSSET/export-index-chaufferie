# Documentation fonctionnelle

Objectif : exporter les index d'abonnés en Excel.

Entrées : fichiers `NN_Nom.txt`, une date française suivie d'une tabulation et d'un index numérique par ligne. La dernière ligne non vide est retenue.

Sortie : `Index_abonnes.xlsx`, onglet Index abonnés (numéro, nom, date, index, fichier source), et onglet Erreurs si besoin.

Limites : aucune consommation calculée, aucune validation de cohérence des index. Vérifier avant facturation.
